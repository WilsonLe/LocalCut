# Prepare images for a LocalCut edit

Inspect the actual source at useful detail before changing it. Establish its output role, aspect ratio, composition, adjacent-shot continuity, branding and whether generative additions/removals were requested. Preserve originals and treat a generated revision as a new asset.

For ordinary placement, cropping through transforms, color treatment, masks and compositing, use LocalCut's actual edit schemas. Inspect the Media asset, then place the image at the intended duration on the existing timeline. Use storyboard artwork when suitable. LocalCut does not include a generative image-editing service; image-generation or object-replacement work requires an available authorized host tool, not an invented WebMCP operation.

For an external image edit, describe the hero subject, supporting objects, surface/background, light/reflections and text/branding. Mark intended elements preserve/modify/replace/remove/add. Inspect camera angle, scale, materials and negative space. Preserve truth-critical details and the accepted style. An external reference requires source identity and an appropriate reuse basis; a search thumbnail is not permission.

For food/product images, do not infer ingredients, allergens, portion size, price, brand claims or preparation from appearance. Do not add garnish, steam, packaging, text or objects without requested generative intent. An altered image cannot establish the originally photographed product/dish. Do not promise pixel-perfect preservation; review the entire result for drift.

Compare source and result for silhouette, product identity, texture, light direction, shadows, geometry, crop room and text accuracy. Reject unexplained source drift. Import a changed image as a new Media asset through the browser chooser; do not overwrite the original or silently substitute every instance. Use current revisions and explicit clip instance IDs for timeline replacement.

Inspect the image within the full video at actual delivery size, including motion/crop extremes and neighboring shots. Record source-to-result lineage and disclose generative alterations where relevant. An optional unavailable image tool should not block ordinary LocalCut assembly. No upload, paid generation or publication is authorized solely by reading this guidance.

Keep visible UI and authored titles/captions focused on the user's content and actions. Do not add storage explanations, implementation notes, workflow narration or filler such as “saved with this asset in your browser.” Include a short explanation only when it changes a concrete user decision or resolves an error. Preserve supplied transcript/content verbatim unless a correction is requested.
