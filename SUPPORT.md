# Getting help

Start with the [first-edit guide](docs/getting-started.md), [troubleshooting](docs/troubleshooting.md) and [privacy guide](docs/privacy.md). For development setup use [README setup](README.md#setup) and the [development guide](docs/development.md). Deployment help lives in [DEPLOY.md](DEPLOY.md).

## Questions, bugs and proposals

Search [issues](https://github.com/WilsonLe/LocalCut/issues) first. Use a [new issue](https://github.com/WilsonLe/LocalCut/issues/new/choose) for a reproducible bug, feature proposal or question. GitHub Discussions and a dedicated chat/support service are not documented project channels. Volunteer support has no guaranteed response time.

A useful report contains:

- The app URL/base path, date, browser version, operating system and device type. For a source checkout include the commit and Node/pnpm versions.
- Exact steps, expected behavior, observed behavior, and whether a fresh project/browser profile reproduces it.
- A minimal generated or safely shareable media sample, with container/codec, duration and dimensions where relevant. Filename extensions alone do not establish codecs.
- Redacted error text or screenshots, and the command/test title if reporting a check failure. Performance reports need measured timings and machine/load conditions.

Public issues and attachments are public. Never attach credentials, OAuth callback URLs, personal media, transcripts, private project backups, storage dumps or unredacted request/response bodies. Reproduce with generated media when possible. Do not clear your working browser's storage merely to produce a clean reproduction; use a separate profile or context.

For a feature, explain the editing workflow and its desired outcome, alternatives tried, and privacy/storage/performance implications. A proposal is not a delivery promise. See [roadmap and scope](docs/roadmap.md).

## Preserve work before troubleshooting

Export a project or workspace backup, selecting originals where needed. Keep a copy outside browser storage and test recovery in a separate profile. Browser downloads are separate from autosaved editing data. Changing origins, clearing site data or using private browsing may remove access to saved projects.

For suspected security or privacy vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than posting a public reproduction. Provider account, billing and policy questions also require the provider's support; a configured route does not prove entitlement or successful inference.
