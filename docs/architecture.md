# Architecture

One application package produces the static `index.html` workspace and the independently imported `editor.js` engine. Workspace imports follow content hashes; headless integrations discover the current editor URL through `modules.json`. The public agent AI entry, provider adapters and chat UI have been removed. Heavy media/inference work remains lazy and local.

The design-system configuration is shadcn Base UI, neutral Vega, CSS-first Tailwind 4, light/dark variables, and system fonts by default. Appearance can use the same locally served font catalog as authored text, through lazy settings and font preparation. The workspace uses shared button, dialog, input, select, checkbox, label, textarea and toast components. Its project and preview controls invoke the public editor API; they do not own a second project document.

The eager `ReleaseRecovery` boundary listens for Vite lazy-import failures and catches failed React screens. It offers an explicit reload, without automatically interrupting running work. Reload preserves the project hash and local persistence, uses a fresh HTML query to bypass a cached shell, and removes that temporary query at startup after OAuth secret capture. Repeated failures return to recovery rather than automatically looping. A caught API failure can dismiss the banner and retain the mounted workspace; a failed React tree shows the recovery screen. Initial app-script/network failures still require the browser's own reload.

Headless clients discover hashed editor URLs together through `modules.json`; see [the API contract](api.md). Compatibility aliases cannot invalidate already cached old implementations. Font manifests and WOFF2 files are packaged under `fonts/<snapshot-sha256>/`, with the snapshot identity derived from the catalog lock and every family manifest (including binary checksums). UI and worker font loading share that path and verify binary checksums before constructing a face. An integrity failure makes one HTTP revalidation attempt, then reports a retryable error without publishing corrupt bytes. Source/dev catalog paths remain unversioned; production build/cache checks verify the packaged snapshot.

| Boundary     | Responsibility                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| src/core     | Zod v1 documents, commands, history contracts, captions, keyframes, rational timing, sinc interpolation              |
| src/storage  | IndexedDB transactions, immutable originals, OPFS journals, recovery, LRU derivatives, owned namespaces              |
| src/media    | Explicit container imports, metadata/decode, derivative conversion, composition, streaming export, AAC priming probe |
| src/services | Jobs, worker transport, preview clock, pinned model configuration                                                    |
| src/workers  | Separate interactive and background media workers; dedicated single-thread inference worker                          |
| src/editor   | Disposable asynchronous public facade and events                                                                     |

The project owns ordered tracks, clips, overlays/cues, and explicit transitions. It references assets by stable ID. Browser object URLs, file handles, native samples, decoded bytes, and contexts are runtime resources and never part of project JSON.

Commands operate on a clone. Validation finishes before persistence commits document, history, and receipt in one read/write transaction. That transaction serializes competing tab writes. Receipt lookup precedes revision comparison. Undo and redo restore document state while incrementing the live revision; receipts remain until deletion.

Preview and export use the same OffscreenCanvas renderer and bounded audio mixer. Effects run brightness, contrast, saturation, grayscale, blur on scratch surfaces before layering. Chroma key precedes effects; presets/LUT grading and clip-local geometric/motion masks follow. Layer blend modes share the backdrop in preview/export. Crossfades interpolate independently composited endpoint/backdrop surfaces with premultiplied weights. A black transition covers underlying tracks. Source orientation is applied by Mediabunny's sample drawing. Optional spectral suppression and crossover EQ use bounded haloed output windows; balance attenuates the opposite channel before gain/fades. Local translation tracking produces editable mask motion through a revision/source-keyed durable task. PCM is normalized lazily to 48 kHz stereo; windows include interpolation halos and derive phase from absolute timeline sample indices. Constant speed defaults to changing pitch for compatibility. Optional normalized speed ramps integrate smooth, linear or hold segments; their integral derives duration and source position, and inverse mapping retimes source captions. Keep pitch uses stereo-coherent WSOLA with bounded grains in the same renderer. Each active timed clip owns one stretcher; inactive clips release it. Seeking resets its overlap sequence, so the short overlap transient can differ from uninterrupted playback. Resampling coefficient caches quantize the anti-alias cutoff upward and retain at most 16 tables.

Each active video clip owns a sequential decoder cursor retaining only the current frame and one lookahead frame. Forward playback reuses that cursor; backward or distant seeks restart at the requested source time. Simultaneous clips referencing one asset have independent cursors. Ended clips release samples and iterators, and assets without active clips release their container inputs. This bounds decoding resources during long exports while keeping interactive seeking in its separate worker.

Export freezes a revision, probes both codecs, schedules frames from indices, streams encoded packets to a temporary OPFS file, and publishes after finalization. Audio ends at the rounded video endpoint. AAC priming is measured for the exact native configuration through an impulse encode/decode probe; timestamps remove that delay and final packets trim encoder padding. Hardware output bytes may differ between runs.

Jobs have an ID, completion promise, progress subscription, and cancellation. Media work yields regularly and observes cancellation; inference cancellation terminates its dedicated worker. Terminal events are structured. Worker crashes reject pending work and subsequent jobs create a new worker.

The lightweight workspace shell and project browser render in the initial UI graph within the existing bundle budget; heavy editing panels, media and dialogs remain lazy. Pinned React Router stays mounted while those regions load so navigation is preserved. React Router owns hash navigation at both static bases. Workspace hooks own validated route identity, an atomic engine snapshot and asset view, cancellable project navigation and the saved-project catalog. Components consume the hooks rather than duplicating route or catalog state; editing commands still use the engine facade. Fresh startup remains inert. Initial bare navigation with a validated recent-project identity replaces the route and restores that local saved project through the same navigation owner; explicit URLs retain priority. The separate recent-project localStorage record never supplies editable content or authorizes inference. No service worker, cloud backend or engine control window global exists. The optional Storyboard UI sets Excalidraw's documented asset-path global to locally served fonts; its project data and editing commands remain behind the shared facade. All user controls share the editor facade. Product agent AI has been removed; see [the removal contract](ai.md).

## Enforced dependency direction

The composition roots (`main.tsx`, `App.tsx`) and workspace mount UI. Runtime layers (`core`, `editor`, `storage`, `media`, `services`, `workers`, `lib`) cannot statically import/re-export or literally dynamically import `workspace`/`components`. Core additionally cannot import the higher runtime layers, React or browser libraries, use dynamic imports or access browser globals. ESLint handles relative and `@/` paths; computed runtime targets and indirect dependencies still need review. This is a checked subset of the ownership table, not a claim that every possible graph cycle is forbidden.

`Workspace.tsx` composes navigation, engine lifecycle and panels. `useTimelineEditing.ts` binds timeline actions to the shell's revision-aware `apply` and error owner, owning only the session clipboard. `useWorkspaceLayout.ts` owns responsive panel state and focus recovery using the existing persisted preferences. Neither owns another editable project. Their extraction preserves stable hook call order, current snapshot capture, lazy panel boundaries and the view-only playback clock.

`media-import.ts` coordinates a submitted file/directory selection through engine-owned jobs, captures its initiating project and serializes library placement across batches. `useMediaImport.ts` owns only temporary progress display, dismissal and the shared placement ref. The shell invokes this path from file inputs, app/Media drops and recording. Dismissal removes the view without cancelling jobs; navigation cannot redirect their placements, and unmount suppresses late view publication. The existing lazy folder classifier remains behind an explicit import. The coordinator is invoked only in event callbacks, preserving inert render/startup.
