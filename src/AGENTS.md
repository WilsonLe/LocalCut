# Application and runtime

Applies throughout `src/`, together with the root guide. Read the nearest module `AGENTS.md` before changing its code. Use [architecture](../docs/architecture.md) for boundaries and [API contracts](../docs/api.md) for shared behavior.

- Preserve the client-only static application, `editor.js` and `ai.js` entries. Load media, inference and optional settings on demand; resolve worker/assets through Vite-supported module URLs.
- Bare app navigation without a project route or validated remembered recent-project identity must not create an editor, open IndexedDB/OPFS editing storage, start workers, request permissions or fetch models/AI. Reading local UI preferences and display-only project catalog summaries before rendering is allowed; cached summaries never authorize opening storage or hydrate editable documents. Explicit create/open/import actions, valid project or project-catalog routes, and initial bare navigation with a validated remembered recent-project identity initialize local editing. Project URLs restore only an existing local project; they must not create one, request remote models, or start paid work. An explicit OpenRouter OAuth return may finish authentication after removing callback secrets. A previously saved credential may restore AI and refresh the catalog; it must not initialize editing or start paid work.
- UI and external transports use the shared editor/assistant APIs. Keep one canonical project document; carry authored revisions and request IDs through mutations.
- Persist stable IDs, integer microseconds, rational frame rates and half-open intervals. Never persist object URLs, native handles or media bytes inside project JSON. Follow the local core/storage guides for validation and atomicity.
- Keep source media and transcription local by default. An explicitly configured remote STT route may receive selected source audio only after a transcription proposal discloses all possible recipients and the user approves it; configuration changes retire pending proposals. Model/runtime downloads require explicit preparation. Optional remote chat, separately consented derived indexing evidence and speech synthesis remain in `ai/`, behind explicit sharing choices or a Generate action; speech synthesis sends the authored script and speech settings, plus an explicitly selected saved generated voice reference and its matching transcript when Generate discloses that upload. Explicitly choosing the configured STT route in the speech dialog permits Generate to send only the newly generated audio to disclosed recipients for phrase timing; transcript-text sharing remains separate. Never select project source media automatically.
- Follow [persistent computation](../docs/development.md#persist-reusable-computation) for new or changed derived work. Reuse valid local results across refreshes; update the storage inventory and prove fresh-worker reuse, invalidation and recovery.
- Keep native samples, bitmaps, workers, streams and audio nodes owned and disposable. Cancellation/disposal must prevent stale results from being published.
- Use the existing semantic styles and shadcn/Base UI foundation, with system fonts as appearance defaults. Appearance and authored text share the pinned, locally served font catalog; prepare faces independently in each rendering realm. Keep the full appearance catalog lazy on default startup and restore saved selected fonts without opening editing services. Report asynchronous progress and errors accessibly through the owning consumer.

Start with the changed module's focused check, then use the [development guide](../docs/development.md) for the applicable integration gate. Updating entry imports, worker paths or shared source boundaries requires both static builds and bundle checks.
